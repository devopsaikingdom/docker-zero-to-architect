# 🐳 Docker: Zero to Architect — The 100-Image Course

> **DevOps AI Kingdom** | From Zero to Architect

A 100-lesson series that takes you from your first container to architect-level Docker mastery, building the **SecureBank** platform along the way.

## 🎯 What You'll Build

Every lesson produces a real Docker image. By Lesson 100, you'll have:
- A complete understanding of containers from process-level to architect-level
- A production-grade **SecureBank** platform (6 microservices)
- A signed, scanned, attested image supply chain
- Skills that map directly to CKA, CKS, and AWS certifications

## 📚 Course Structure

### Tier 1 — Foundations (Lessons 1-25) ✅
From `docker run hello-world` to pushing your first image to a registry.

### Tier 2 — Real Builds (Lessons 26-50) 🔜
Containerize real applications, multi-stage builds, Compose, SecureBank services.

### Tier 3 — Production Hardening (Lessons 51-75) 🔜
Security scanning, SBOM, signing, distroless, CI/CD gates.

### Tier 4 — Architect (Lessons 76-100) 🔜
Supply chain security, image promotion, golden bases, cost optimization.
